title: "Custom indicators"
description: "Write your own indicators for Darvas charts in Pine Script v5 or v6, describe one to the Darvas assistant, or paste a TradingView script."
---

A custom indicator is a Pine Script that Darvas runs on your chart. You can write the script yourself, paste one from TradingView, or describe what you want and let the Darvas assistant write it. Darvas runs Pine v5 and v6 as written and rewrites older versions to v5.

```pine
//@version=6
indicator("My indicator", overlay=false)
len = input.int(14, "Length", minval=1)
rsi = ta.rsi(close, len)
plot(rsi, "RSI", color=color.purple, linewidth=2)
hline(70, "Overbought", color=color.gray)
hline(30, "Oversold", color=color.gray)
```

This script is the template a new indicator starts with. It draws a 14-bar RSI in its own pane with lines at 70 and 30.

## Where a script runs

- A script you have not saved runs in your browser, in a sandboxed frame that has no network access.
- A saved indicator runs on Darvas servers. That is how an alert can check it while Darvas is closed, and how a shared indicator can hide its code.
- Every run reads the newest 1,000 candles of the chart.
