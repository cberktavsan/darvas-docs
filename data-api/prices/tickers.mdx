## Overview

The tickers [`/prices`](/data-api/prices/historical) answers, in order. `/prices/snapshot/tickers` gives the same list for [`/prices/snapshot`](/data-api/prices/snapshot), since every stock with bars has a snapshot.

## Example

```bash
curl -H "X-API-KEY: $DARVAS_API_KEY" https://darvas.app/api/data/v1/prices/tickers
```
