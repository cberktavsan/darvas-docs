## Overview

The tickers [`/prices/snapshot`](/data-api/prices/snapshot) answers, in order: every stock with bars.

## Example

```bash
curl -H "X-API-KEY: $DARVAS_API_KEY" https://darvas.app/api/data/v1/prices/snapshot/tickers
```
