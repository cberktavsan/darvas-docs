## Overview

One row per transaction reported on Form 4 or 5, newest filing first. Each row joins the transaction with its filing, its reporting owners and its footnotes.

| Coverage | Details |
| --- | --- |
| History | Since January 2006, from SEC's Insider Transactions Data Sets |
| Updated | Within about a minute of acceptance, from each new filing's XML |
| Forms | 4, 4/A, 5, 5/A |
| Page size | 100; `limit` counts across pages, up to 10,000 |

`name` and `title` describe the first reporting owner; joint filings list every owner in `reporting_owners`. `shares_owned_before_transaction` is computed from the shares held after the trade and the amount acquired or disposed of. `is_10b5_1_plan` is the box the filer ticked for a Rule 10b5-1 trading plan. Derivative rows, such as option exercises, set `is_derivative` and the underlying security.

## Transaction types

`transaction_type` accepts SEC's one-letter code or its name, in any case.

| Code | Type | Code | Type |
| --- | --- | --- | --- |
| P | Purchase | M | Option exercise |
| S | Sale | C | Conversion |
| A | Award | X | In-the-money exercise |
| D | Disposition to issuer | G | Gift |
| F | Tax withholding | J | Other |

The full list of 20 codes is in the [SEC Form 4 instructions](https://www.sec.gov/files/forms-3-4-5.pdf).

## Filtering

- `name`: insiders whose name contains the text, in any case.
- `transaction_type`: a code or a type from the table.
- `form_type`: one of `4`, `4/A`, `5`, `5/A`.
- `filing_date`, `filing_date_gte`, `filing_date_lte`, `filing_date_gt`, `filing_date_lt`: ISO dates.

## Examples

```python
import os
import requests

headers = {"X-API-KEY": os.environ["DARVAS_API_KEY"]}
url = "https://darvas.app/api/data/v1/insider-trades"

purchases = requests.get(
    url,
    headers=headers,
    params={"ticker": "NVDA", "transaction_type": "Purchase", "filing_date_gte": "2025-01-01", "limit": 50},
).json()["insider_trades"]

for trade in purchases:
    print(trade["filing_date"], trade["name"], trade["transaction_shares"], trade["transaction_price_per_share"])

# Sales made under a pre-arranged plan
planned = requests.get(url, headers=headers, params={"ticker": "NVDA", "transaction_type": "S", "limit": 100}).json()
print(sum(1 for t in planned["insider_trades"] if t["is_10b5_1_plan"]))
```
