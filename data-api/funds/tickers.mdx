## Overview

The share class tickers [Index Fund Holdings](/data-api/funds/holdings) answers for, from SEC's list of fund tickers, for funds with an N-PORT report in the last 15 months.

```bash
curl -H "X-API-KEY: $DARVAS_API_KEY" \
  "https://darvas.app/api/data/v1/index-funds/tickers"
```
